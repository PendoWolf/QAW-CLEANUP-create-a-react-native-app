# QAW Counter

A small [React Native](https://reactnative.dev) counter app for iOS and Android, bootstrapped with
[`@react-native-community/cli`](https://github.com/react-native-community/cli) (no Expo).

Increment or decrement the count by a step of 1, 5 or 10, and reset it to zero.

## Run it

1. Install dependencies: `npm install`
2. Start Metro: `npm start`
3. In another terminal:
   - Android: `npm run android`
   - iOS: `bundle install`, then `cd ios && bundle exec pod install && cd ..`, then `npm run ios`

## Test

`npm test`
